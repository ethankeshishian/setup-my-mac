# smm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the copy-based `setup-my-mac.sh` with a nix-darwin + home-manager flake driven by one `smm` command (setup, apply, sync, add, remove, status, upgrade, undo) that never leaves an app on a broken config.

**Architecture:** The flake declares the system (packages, Homebrew casks, macOS defaults, launchd services) and links every hand-tuned config straight into the repo with `mkOutOfStoreSymlink`. The lists that `smm` edits (linked configs, Homebrew packages, Nix packages, secrets) live in JSON manifests that Nix reads with `builtins.fromJSON`, so `smm` never edits Nix code. `smm` is a bash program packaged with `writeShellApplication` (shellcheck runs at build time), split into small sourced libraries, and tested with bats using PATH stubs for system tools and real temporary git repos for sync and undo.

**Tech Stack:** Nix (Determinate installer, flakes), nix-darwin, home-manager, nix-homebrew, bash, jq, bats-core, shellcheck, gitleaks.

**Spec:** `docs/superpowers/specs/2026-11-09-smm-nix-design.md`. Read it before any task.

## Global Constraints

- Only Ethan's Apple Silicon Macs (`aarch64-darwin`), macOS 27. User `ethankeshishian`. First host `Ethans-MacBook-Pro`.
- Repo path is fixed: `~/Repos/setup-my-mac`. Linked configs point there.
- **No Claude attribution in any commit message**: no `Co-Authored-By`, `Claude-Session` or "Generated with" lines.
- Public repo: no secrets in the repo, ever, not even encrypted. Secrets come from 1Password `op` and are written outside the repo or to gitignored paths.
- `nix.enable = false` (Determinate manages Nix).
- Homebrew: nix-darwin `homebrew.onActivation.cleanup = "none"`, `autoUpdate = false`, `upgrade = false`. `smm` alone removes undeclared packages, and only those Ethan confirmed.
- Ghostty comes from the **stable** Nix package; the `ghostty@tip` cask is removed at migration.
- AeroSpace config stays a linked file. Never use `services.aerospace.settings`.
- Borders values: `active_color=0xff3a6aff inactive_color=0x00494d64 width=12.0`.
- `sync` prompts for a commit message; `-m "<msg>"` skips the prompt. Nothing to commit means no prompt.
- **Nothing in Tasks 1–20 may change the live Mac** beyond installing Nix (Task 1). Build with `darwin-rebuild build` only, never `switch`, and never touch real files in `$HOME`. Task 21 is the attended migration.
- State dir: `~/.local/state/smm/`. Backup dir: `~/.smm-backup/<YYYYmmdd-HHMMSS>/`.
- Every `smm` command is safe to re-run.

## Review Focus

1. **launchd PATH:** SketchyBar runs under launchd, where `aerospace` isn't on PATH, so the bar would come up with no spaces. Expected: the service can call `aerospace`. Pinned by the Task 3 eval test (`extraPackages` includes aerospace) and by the Task 9 health check (number of space items equals the number of workspaces).
2. **Lost Accessibility after an upgrade:** an AeroSpace upgrade changes the binary, macOS drops the grant, and AeroSpace stops managing windows. Expected: `smm` says so and waits on the permission pane; it doesn't roll back blindly. Pinned in Task 9 (health reason `no-accessibility`) and Task 15 (upgrade routes that reason to the permission wait).
3. **Dirty tree during upgrade or undo:** the `upgrade:` commit would sweep up unrelated edits. Expected: refuse, with "commit or sync first". Pinned in Tasks 15 and 16.
4. **Offline or unreachable remote during sync:** expected to fail before any local change, with a clear message. Pinned in Task 13.
5. **Karabiner writes `automatic_backups/` inside the linked directory**, so backups would be committed to the public repo. Expected: they're gitignored. Pinned in Task 2.

### Task 6: Validators

**Files:**
- Create: `smm/lib/validate.sh`, `smm/cmd/validate.sh`, `smm/tests/validate.bats`

**Interfaces:**
- `smm_validate <root> [names...]` → for each link with a non-null validator (all of them if no names are given), runs `validate_<validator> "<root>/<source>"`. Prints `ok <name>` or `fail <name>: <first error line>` per link. Returns 0 only if all pass. Exports `SMM_FAILED_LINKS` (space-separated).
- Validators:
  - `validate_aerospace <file>`: AeroSpace's dry run reads only the live path, so: if `~/.aerospace.toml` is already `<file>` (or links to it), run `aerospace reload-config --dry-run --no-gui`. Otherwise, swap: move the existing `~/.aerospace.toml` (file or link) to `$SMM_STATE/aerospace.swap`, symlink `<file>` in its place, dry-run, then restore in a `trap … RETURN EXIT INT TERM`. It must restore even on Ctrl-C.
  - `validate_ghostty <dir>`: `ghostty +validate-config --config-file=<dir>/config`
  - `validate_karabiner <dir>`: `jq empty <dir>/karabiner.json`, then extract each profile's `complex_modifications.rules` into a temp file shaped `{"title":"smm","rules":[...]}` and run `karabiner_cli --lint-complex-modifications <tmp>`
  - `validate_sketchybar <dir>`: `bash -n` on `sketchybarrc` and every `*.sh`
  - `validate_tmux <file>`: `tmux -L smm-validate -f /dev/null start-server \; source-file -n <file> \; kill-server`
  - `validate_zsh <file>`: `zsh -n <file>`
  - `validate_plist <file>`: `plutil -lint <file>`
  - `validate_nvim <dir>` (used from Task 17): make a temp `XDG_CONFIG_HOME` with `nvim → <dir>`, run `nvim --headless "+lua vim.defer_fn(function() if vim.v.errmsg ~= '' then vim.cmd('cq') else vim.cmd('qa') end end, 2000)"`. It fails on a non-zero exit or on stderr matching `E[0-9]+:|Error`.

### Task 19: `smm setup`

**Files:**
- Create: `smm/lib/setup.sh`, `smm/cmd/setup.sh`, `smm/tests/setup.bats`

**Interfaces:**
- The step framework: `SETUP_STEPS=(...)`. Each step `s` has `step_<s>_done` (checks **real** state; returns 0 if done) and `step_<s>_run`. `cmd_setup [--preview]` loops: if done, skip; otherwise run; if it fails, stop with `"setup stopped at <s>: <reason>. - `smm_need_restart <reason>` → appends to `$SMM_STATE/restart-needed`. Only the final step reads it.
- Steps, in order:
  1. `preflight`: arm64, repo at the fixed path, on `main`
  2. `nix`: `nix --version` works and the daemon is healthy; otherwise `/nix/nix-installer repair` (or install)
  3. `host`: `hosts/$(scutil --get LocalHostName).nix` exists; if not, ask for a name, copy `template.nix`, set all three names

  8. `dedupe`: for each Homebrew formula or cask that's also in `nix-packages.json` (sketchybar, borders, aerospace, neovim, tmux, …), `brew services stop` / quit the app, then `brew uninstall`. The list goes to `$SMM_STATE/deduped`.
  9. `switch`: `smm_switch`. If it fails, reinstall everything in `deduped` with brew, restart it, and stop.
  10. `permissions`: `smm_wait_permission aerospace`, `smm_wait_permission karabiner`

  14. `health`: `smm_health`
  15. `commit`: if the repo changed, `sync`-style commit (prompting for a message) and push if GitHub is signed in
  16. `finish`: list what's left to do by hand; if `restart-needed` isn't empty, list the reasons and `confirm "Restart now?"` → `osascript -e 'tell app "System Events" to restart'`
